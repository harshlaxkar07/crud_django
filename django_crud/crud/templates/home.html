Member Directory

A complete create, read, update and delete workflow built on Django's models, forms and validators. Records are validated before they are written and every action reports back what happened.

Browse members Add a member

Create

A model form collects the details and Django's validators check them before anything reaches the database.

Read

Every member is listed in one table with contact details, age and a record identifier you can act on.

Update

The same form is reused for editing, pre-filled from the existing record so corrections take one click.

Delete

Removing a record asks for confirmation first, then reports the result through Django's messages framework.
